# Support

## Getting help

- **Bugs and feature requests** — open an issue in the relevant
  repository using the issue template.
- **Questions and general discussion** — use
  [GitHub Discussions](https://github.com/orgs/vergil-project/discussions)
  on the relevant repository.
- **Documentation** — reference material is available at the
  [VERGIL docs site](https://vergil-project.github.io/vergil-tooling/).

## Which repo?

| Topic | Repository |
|---|---|
| CLI tools (`vrg-commit`, `vrg-validate`, etc.), git hooks | [vergil-tooling](https://github.com/vergil-project/vergil-tooling) |
| CI/CD workflows, GitHub Actions | [vergil-actions](https://github.com/vergil-project/vergil-actions) |
| Dev container images, Dockerfiles | [vergil-docker](https://github.com/vergil-project/vergil-docker) |
| Claude Code plugin, AI agent hooks and skills | [vergil-claude-plugin](https://github.com/vergil-project/vergil-claude-plugin) |
| Org-level templates, community health files | [.github](https://github.com/vergil-project/.github) |

If you're unsure which repo is relevant, pick the closest match and
the maintainer will route it.

## Expectations

VERGIL is a community project maintained by volunteers. There is no
SLA-backed support. Issues and discussions are addressed as time
permits. We appreciate your patience.
